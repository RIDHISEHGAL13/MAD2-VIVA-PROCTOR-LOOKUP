# MAD2 VIVA PROCTOR LOOKUP

Deployed at: [https://mad2-viva.netlify.app/](https://mad2-viva.netlify.app/)

This is a [Next.js](https://nextjs.org) project designed to look up MAD2 Viva Proctors.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
